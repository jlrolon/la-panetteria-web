# 🥖 La Panetteria — Propuesta de Sitio Web

Este repositorio contiene la maqueta funcional y propuesta de sitio web interactivo para **La Panetteria** (San Miguel, Buenos Aires).

El objetivo del sitio es conectar la presencia minorista de la marca con su escala de producción industrial y logística de distribución B2B.

---

## 🚀 Características Principales

- **Diseño Responsive:** Adaptado para teléfonos móviles, tablets y computadoras.
- **Sección B2B / Mayoristas:** Formulario de cotización e información para comercios, autoservicios y distribuidores.
- **Presentación de Planta Industrial:** Destacado de procesos estandarizados, envasado en ambiente controlado y logística refrigerada.
- **Catálogo de Especialidades:** Presentación visual de panificados, pastelería y línea de empaquetados.
- **Integración Directa:** Botonera flotante y accesos directos a WhatsApp e Instagram.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5**
- **Tailwind CSS** (vía CDN)
- **FontAwesome Icons**
- **Google Fonts** (Playfair Display & Plus Jakarta Sans)
